# 冰壶制冰师模拟器 · Ice Maker Sim

一款模拟冰壶场制冰师工作的物理模拟游戏。玩家在赛前一层层浇水冻出平整基础冰、倒退着洒出卵石点、用刮刀削顶，再在比赛局间对抗结霜与磨损，按冰速稳定性、左右一致性、走线和结霜控制接受评分。

## 运行

```bash
npm install
npm run dev        # 开发服务器(默认 http://localhost:5397)
npm run build      # 类型检查 + 生产构建
npm run preview    # 预览生产包
```

测试与标定:

```bash
npm run calibrate  # 物理标定:摩擦/接触面/霜/密度的冰速响应,不依赖浏览器
npm run test:rules # 引擎规则:判废、结霜、削顶、场馆差异
npm run test:smoke # 无头浏览器全流程冒烟(需先 npm run dev)
```

## 四个页面

| 页面 | 职责 |
| --- | --- |
| 制冰作业 | 浇水(厚度/水温/均匀度)、倒退洒点(水温/水箱高度/喷头孔径/步速)、刮刀削顶、开赛 |
| 冰面检测 | 高低差热图、>1mm 红格标注、左右半幅高差、卵石点统计、双向试滑壶计时与走线 |
| 场馆环境 | 3 种场馆 + 3 套制冷系统、管温/室温/湿度/观众/除湿机控制、实时露点与霜厚 |
| 赛事评价 | 每局四维评分与 S/A/B/C/D 等级、逐局历史、判废记录、综合总成绩 |

## 物理模型(`src/engine/`)

- **冻结时间** `thermal.ts`:层冻结时间随厚度平方增长,乘管温、水温、机组效率系数;制冷管温度对设定值做一阶滞后响应;马格努斯公式算露点。
- **冰面高度场** `icefield.ts`:96×48 网格,浇水叠加条状起伏,每层冻透时自流平收敛;提供横坡采样(壶的跑偏)与高低差/红格统计。
- **卵石点** `pebble.ts`:水珠直径由喷头孔径、水箱高度(托里拆利水压)、水温(黏度)决定;步速决定落点密度;落地按体积守恒铺成半球;刮刀按几何求接触圆面积比。数据采用**原生交错 AoS 布局**,与 GPU 实例缓冲零拷贝。
- **摩擦与滑行** `friction.ts` / `stone.ts`:μ(v)=μ₀+μ₁·v^1.5 的速度弱化模型(标定后标准状态前掷线用时≈24.5s),再乘接触面、点密度、霜、冰温、粗糙度因子;横坡经重力分量产生横向加速度。
- **结霜** `frost.ts`:相对湿度超 65% 且冰温低于露点时凝华成霜,霜厚直接进入摩擦因子拖慢冰速,除湿机可抑制。
- **评分** `scoring.ts`:冰速稳定 35% / 两侧一致 30% / 走线 25% / 结霜控制 10%。

所有摩擦参数由 `scripts/calibrate.ts` 在浏览器外标定,确保响应方向和量级正确(削顶呈 U 型冰速、霜越厚越慢、光板冰惩罚等)。

## 渲染性能

- 原生 **WebGL2**,卵石点用 `drawArraysInstanced` 单 draw call,单赛道最多 42 万实例。
- 实例数据物理与渲染共用同一块 `Float32Array`,上传零 CPU 拷贝;冻结进度增量维护,统计量缓存。
- 提供 标准/高/全量 三档 LOD。硬件 GPU(D3D11/ANGLE-GL)实测全量 37 万实例稳定 100–140 FPS。
  注:无头环境若回退到 SwiftShader 软件渲染,其对 instanced attribute divisor 模拟很慢(个位数 FPS),属驱动限制而非应用瓶颈。

## 判废规则

- 基础冰未冻透(或浇得太厚没冻透)就洒点 → 赛道判废。
- 卵石点未冻硬就上刮刀 → 点被成片带飞,判废。
- 判废记录显示在赛事评价页并弹出提示。
