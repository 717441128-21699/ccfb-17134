# 冰语制冰师 · Curling Ice Maker Lab

一个赛前冰壶场制冰模拟游戏。玩家需要分层浇水、等待冻透、刮平基层、背箱倒退洒出几十万颗卵石点、按物理参数削顶，并在观众、湿度、霜和运动员磨损之间保障 6 局比赛的冰速稳定。

## 启动

```bash
npm install
npm run dev
```

浏览器打开 Vite 输出的地址（默认 `http://127.0.0.1:5173`）。推荐使用支持 WebGL2 和 GPU 实例化的最新版 Chrome / Edge。

生产构建：

```bash
npm run build
npm run preview
```

## 页面

- **制冰作业**：分层浇水、冻结进度、基层刮平、洒点参数、倒退走行进度、卵石削顶。
- **冰面检测**：WebGL2 高差标红、全场热力图、左右双道试滑、秒数/偏移/摩擦系数。
- **场馆环境**：4 种虚构场馆与制冷系统，盘管温度、室温、湿度阈值、除湿机和观众负荷。
- **赛事评价**：6 局评分、左右一致性、走线、冰速稳定性、冻透合规和局间建议。

## 关键规则

- 局部约 0.9m 检测窗口内的高低差超过 **1mm** 时，WebGL2 冰面和热力图会标红。
- 试滑计时门为前掷线 `z=-13.5m` 到后掷线 `z=+13.5m`，目标约 **12.60s**；秒数随卵石密度、接触面积/削顶量、冰温、霜量和磨损变化。
- 单层厚度 ≥1.6mm 且尚未冻透时开始洒点，会形成“夹生层”，赛道直接判废、赛事总分按 0 处理。
- 湿度高于设定阈值且冰温低于 0°C 时会积霜；霜会提高摩擦系数、降低冰速。
- 每局后观众湿度、卵石磨损和细微起伏都会变化，需要局间重新削刮、除湿、补点。

## 物理与计算口径

所有模拟计算均为 TypeScript，位于 `src/game/`：

- 冻结时间：水的显热 + 凝固潜热，结合制冷系统热阻、冰层导热和盘管温差的 Stefan 近似。
- 洒点流量：孔口出流 `Q = CdA√(2gh)`。
- 水珠/卵石：由孔径、水温、水箱高度、走行速度计算粒径；体积守恒换算半球半径。
- 削顶接触：`a = √(R²-h²)`，并由密度得到接触面积占比。
- 冰速：积分冰壶在长度方向和横坡上的运动；摩擦项包含密度失配、接触面积、均匀度、磨损、冰温、霜和左右高差。
- 场馆：`北境 / 港湾 / 高原 / 老馆` 四套虚构系统，热阻、气候惯性和湿度基线不同。

这些公式是为游戏可读性做的工程化近似，不是竞技制冰的精确 CFD/热力学模型。

## WebGL2 性能

`src/render/IceRenderer.ts` 使用：

- 一张位移冰面网格和程序化冰壶标线纹理；
- 一次 `drawElementsInstanced` 绘制全部卵石；
- 每颗卵石的位置、基础冰高、半径、削顶后高度和随机明暗放在一个实例缓冲中；
- 低多边形削顶半球剖面；
- DPR 上限和低帧率时的自适应分辨率。

默认参数约生成 **38 万颗卵石**，硬上限为 500,000 个实例。实际帧率取决于 GPU；HUD 会显示 FPS、DPR 和实例数量。

## 浏览器冒烟脚本

```bash
# 另一个终端先运行 npm run preview -- --port 4173
node scripts/smoke.mjs
node scripts/sweep.mjs
```

脚本使用本机 Chrome + Puppeteer Core，不会下载浏览器。`smoke.mjs` 验证完整制冰/试滑/评分/判废流程；`sweep.mjs` 检查密度、削顶和霜对冰速的影响。
