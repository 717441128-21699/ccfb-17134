# 冰锋匠 · 冰壶制冰师模拟(ICE MAKER SIM)

扮演冰壶场制冰师,在比赛前把一条赛道的冰面做出来,并在 6 局比赛之间维护冰面。
全部制冰过程按真实物理模型计算,冰面与卵石点用 WebGL2 实时渲染。

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建
npm run smoke      # Node 端物理冒烟测试(无需浏览器)
npm run e2e        # 浏览器端 E2E(需先启动 dev 与 CDP Chrome,见下)
```

## 四个页面

| 页面 | 内容 |
| --- | --- |
| 制冰作业 | 选场馆/机组、分层浇水、背水箱倒退洒卵石点、刮刀削顶 |
| 冰面检测 | 高低差 >1mm 网格标红、顺/逆时针试滑壶计时、24 分区冰速表 |

## 物理模型(`src/sim/`)

- **分层冻结 — Stefan 导热问题**:`s² = 2·k_ice·ΔT·t /(ρ_ice·L_eff)`,
  冻透时间随厚度平方增长,并计入把水从浇洒温度降到 0°C 的显热;
  接触温度由制冷机组设定温度、换热效率与沿管程均匀性决定。
  冰层没冻透时洒点会被拒绝(真实规则下整面判废)。
- **水滴生成**:Torricelli 水头出流 + 孔口流量系数,体积守恒求滴径;
  Weber 数超临界(Hinze 标度 `d ∝ We^-0.42`)后射流破碎成更细的滴。
  滴径由水温、水箱水头、喷头孔径、流量、孔数共同决定,倒退走速决定落点密度。
- **卵石点球冠**:落滴在负温冰面摊成球冠,体积守恒数值求冠高,
  冰温越低摊得越小;削顶后按球截面几何求壶底接触圆面积。
- **摩擦与冰速**:摩擦系数 = 基准 μ × 密度项 × 接触面积项 × 冰温水膜项
  × 结霜项 × 磨损项;试滑壶用 RK4 积分(摩擦减速 + 旋转侧偏 curl + 冰面坡度跑偏),
  给出前掷线→后掷线秒数与横向偏移。
- **结霜**:Magnus 公式比较空气水汽压与冰面饱和水汽压,
  馆内湿度高于警戒值时水汽在冰面凝华,霜层抬升摩擦、冰速下降。
- **场馆环境**:人群散热散湿与空调/除湿机的质量-热平衡,
  保温差的场馆室温湿度波动更剧烈。

## 渲染性能(`src/render/renderer.ts`)

- 卵石点单次实例化绘制,缓冲上限 42 万;双 LOD 半球(近景 360 顶点/远景 108 顶点)。
- 每 12 帧按相机位置做距离剔除并把可见实例压缩进紧凑缓冲,近/远各一次 draw call。
- 冰面为 48×458 高度场,单条 TRIANGLE_STRIP 索引,高度与标红走 R32F/R8 纹理。

## 虚构场馆与机组

4 种场馆(城市标准馆 / 旧厂房改造馆 / 高原训练馆 / 临时篷房馆)×
4 种制冷系统(乙二醇机组 / 氨泵直冷 / 老式风冷 / 便携模块橇),
参数差异直接进入冻结、冰温均匀性与环境模型。
